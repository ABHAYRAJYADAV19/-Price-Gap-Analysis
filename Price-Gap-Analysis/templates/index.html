How to Use This Dashboard

Welcome to the Price Gap Analysis Dashboard! This tool helps you analyze the difference between seller-listed prices and customer-paid prices to optimize your pricing strategy. Follow these simple steps to get started:

1

Choose Analysis Type

Select the type of analysis that best suits your needs:

  • Basic Analysis: Quick overview of price gaps
  • Advanced Analysis: Detailed trends and forecasting
  • Comprehensive Analysis: In-depth analysis with AI recommendations
2

Prepare Your Data

Ensure your data file meets these requirements:

  • CSV or Excel format (.csv, .xlsx, .xls)
  • Contains required columns (see File Requirements tab)
  • Data is clean and consistent
3

Upload Your File

Upload your prepared data file:

  • Drag and drop your file into the upload area
  • Or click "Browse Files" to select from your computer
  • Verify the file name appears correctly
4

Analyze and Review Results

Process your data and interpret the results:

  • Click "Analyze Data" to process your file
  • Review the price forecast chart
  • Check the fair price recommendation
  • Examine price gap statistics

File Requirements

To ensure accurate analysis, your data file must meet the following requirements:

Supported File Formats

CSV Files (.csv)
Comma-separated values file with UTF-8 or Latin-1 encoding
Excel Files (.xlsx, .xls)
Microsoft Excel spreadsheets (both modern and legacy formats)

Required Columns

Your file must contain the following columns with the exact names listed:

Column Name Description Data Type Example
Invoice Invoice number/identifier String/Number "536365" or 536365
StockCode Product code/identifier String/Number "85123A"
Description Product description String "WHITE HANGING HEART T-LIGHT HOLDER"
Quantity Number of items purchased Number (positive) 6
InvoiceDate Date of transaction Date/Datetime "12/1/2010 8:26" or "2010-12-01"
Price Unit price of product Number (positive) 2.55
Customer ID Customer identifier String/Number 17850
Country Country of customer String "United Kingdom"

Data Quality Requirements

For the best analysis results, ensure your data meets these quality standards:

  • No missing values in required columns
  • Positive values for Quantity and Price
  • Valid date format for InvoiceDate
  • Consistent units for Price (e.g., all in USD)
  • Sufficient data volume - at least 100 transactions for meaningful analysis
  • Recent data - include recent transactions for accurate forecasting

Frequently Asked Questions

Find answers to common questions about using the Price Gap Analysis Dashboard.

General Questions

What is price gap analysis?

Price gap analysis examines the difference between the price sellers list for products and what customers actually pay. This helps businesses optimize pricing strategies to maximize revenue while remaining competitive.

How often should I run this analysis?

For best results, run the analysis monthly or quarterly to track pricing trends over time. More frequent analysis may be beneficial during periods of high market volatility or seasonal changes.

Which analysis type should I choose?

Start with Basic Analysis if you're new to price analysis. Advanced Analysis provides more detailed forecasting, while Comprehensive Analysis offers the most in-depth insights with AI-powered recommendations. You can compare results from different types.

Technical Questions

What if my file doesn't have all the required columns?

The analysis requires all the specified columns to function properly. If your data is missing some columns, consider adding placeholder values or mapping your existing columns to match the required format.

Is there a file size limit?

Yes, the maximum file size is 16MB. If your file is larger, consider filtering the data to include only the most recent or relevant transactions.

How is the fair price calculated?

The fair price recommendation is calculated based on historical customer-paid prices, market trends, and forecasted future prices. The algorithm considers seasonal patterns and price elasticity to suggest an optimal price point.

What if I get an error during analysis?

Common errors include missing columns, invalid data formats, or insufficient data. Check the error message for specific guidance, ensure your file meets all requirements, and try again. If problems persist, try using our sample file format.
